## 🧠 Sobre Mim

Sou **Engenheiro de Dados** em formação e hoje construo **pipelines de dados de ponta a ponta e soluções de Machine Learning** na **Amenco Peanuts**, no agronegócio: extração, tratamento, armazenamento e disponibilização de dados com **Python, SQL Server e PostgreSQL**, além de aplicações em Python + Angular seguindo **Domain-Driven Design**.

Antes, na **Gattaz Health**, participei da fundação da área de dados da empresa: ETL automatizado, redesign do schema PostgreSQL de dados clínicos, APIs com FastAPI e relatórios em Power BI.

Minha base metodológica vem da pesquisa: **bolsista FAPESP** (Living Labs no agronegócio) e **CNPq/OBA**, coautor de **2 capítulos de livro publicados** e **3º lugar no DSIN Coder Challenge 2025**.

**Objetivo:** atuar como _Full Cycle Data Scientist_ — da engenharia ao modelo em produção, do pipeline ao painel analítico.
